Wireframes — Arabic-first courses platform, public pilot

Pure low-to-mid-fidelity wireframes for the OPTO 2311 pilot (Geometric Optics, كلية العلوم الصحية), rebuilt from lecture transcripts and shipped as a static site. Open any file directly in a browser — no build step, same as the pilot site.

Style contract (applies to every frame)

  • Black outlines and black text only; very light gray fills used only to distinguish (done-nodes, placeholders, dimmed drawer background).
  • No color, no shadows, no gradients, no decorative radius, no motion.
  • dir="rtl" on every product frame; visible marker line «اتجاه القراءة: ⟵» at the top.
  • Mixed direction shown honestly: Arabic sentences with inline LTR islands for English terms and math (θᵢ = θᵣ, n₁ sin θ₁ = n₂ sin θ₂, Law of Reflection) — never mirrored away.
  • Wireframe annotations sit in [أقواس] monospace, outside the product voice.
  • Dashed border = empty / locked / placeholder / withdrawn; double outline = keyboard-focus ring.
  • Production font is the Thmanyah family (Serif Text / Sans / Digital) — noted on frames, not simulated: wireframes stay in system fonts.
  • One accent color per course (adopted pattern) is black in this monochrome set, noted where it applies.

Shared facts baked into the frames

  • Header: OPTO 2311 — البصريات الهندسية | كلية العلوم الصحية
  • Banner on every page: هذا المساق قيد الإنشاء — الدروس المقبولة تُنشر تدريجيًا
  • Lesson anatomy (Arabic first): المهارة · لحظة الفهم · مثال محلول · تدريب · اختبر نفسك · مهمة نقل
  • Quiz payload: stable id, skill ref, prompt, 4 choices, answer, rationale, feedback (frame 03).
  • Every lesson carries a source strip: video id + timestamp range (placeholders — recorded from source at generation, never invented).
  • Diagrams: editable Excalidraw source + SVG export; Arabic alt text mandatory.
  • Progress is client-side, survives reload, no account/login — privacy stated in the product's own voice.
  • Accessibility: visible keyboard-focus ring (02, 03, 09), alt-text on every diagram slot, reduced-motion respected, nothing requires motion.
  • House typeface: Thmanyah (noted on frames; wireframes use system fonts). One accent color per course (black here).
  • Arabic UI terminology in the frames is a proposal — Arabic UI wording is an open decision in the brief.
