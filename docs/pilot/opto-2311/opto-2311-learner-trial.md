## 1. Recruitment screen (target 5–8 learners)

Arabic-speaking undergraduates holding the actual course prerequisites. Screen out anyone who already completed an optics course. Record per participant: consent, prerequisite evidence, availability for the 1–2-week delayed variant (only if retention is claimed), and an anonymized participant ID (identifiable data stays in a private store per F18).

Screening questions (template — finalize against the confirmed prerequisite list):
1. Have you passed [prerequisite course **OPEN**]? When?
2. Have you studied [topic **OPEN**] before?
3. Are you comfortable reading Arabic with English technical terms?

## 2. Prerequisite/baseline check (before the lesson)

Short task set checking each screening prerequisite at recall level. Failed prerequisites → either reschedule the participant or record the observation (do not silently proceed; prerequisite gaps are data, not noise).

## 3. Lesson reading + practice session

- Participant reads the accepted lesson and attempts its inline practice exactly as shipped (no hints from the facilitator beyond the script).
- Facilitator script: neutral prompts only ("think aloud", "what are you doing now?"); never teach, never confirm answers.
- Record: time per section, hesitation points, every incorrect attempt, every place the participant re-reads, verbatim confusion quotes.

## 4. Fresh unaided transfer task (scored with the prewritten rubric)

- One task per selected outcome, not shown during the lesson, solved without notes (**OPEN** until outcomes are frozen; one candidate per first-review lecture: pinhole-image prediction / new lens combination / spherocylindrical derivation).
- Scoring rubric written **before** administration; pass criteria per outcome defined in writing; numerical tolerance and acceptable alternative forms stated.
- **Performance criterion (written before the final task): OPEN** — e.g. "outcome X passes if the learner scores ≥ Y on the rubric"; the operator + reviewer must ratify the numbers.

## 5. Observation sheet (per participant, per section)

## 6. Delayed retention variant (only if retention is claimed)

A parallel-form variant of §4 administered 1–2 weeks later; same rubric; no lesson access in between.

## 7. Data handling and limitations

- Answer keys, scoring notes, and identifiable observations stay in the private store; public reports aggregate.
- Retention/deletion choices for participant data: **OPEN**.
- Report limitations verbatim: formative evidence from 5–8 participants; no causal claims; outcomes without direct learner evidence are listed as review-only.

## 8. Report template (fill after the trial)

Criterion verdict per outcome → observed critical failures → revisions made (through correction ledger + invalidation) → reassessment plan for revised teaching → which outcomes have learner evidence → limitations.
